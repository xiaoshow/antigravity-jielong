## 🚀 快速上手

### 1. 运行环境要求

- macOS 系统（Sonoma / Sequoia 或更新版本）
- Python 3.9+（自带标准库 `tkinter`，无需安装任何 pip 依赖）
- Antigravity 官方 CLI (`agy`) 与 Desktop App

---

### 2. 添加并保存你的账号（只需配置一次）

本工具提供自动化账号录入脚本，自动调用官方登录并加密安全备份至本地 `~/.gemini/account_vault/`：

```bash
# 录入 1 号账号（会自动调起浏览器授权并保存为 acc1.token）
python3 tools/antigravity-quota-relay/login_account.py 1

# 录入 2 号账号（保存为 acc2.token）
python3 tools/antigravity-quota-relay/login_account.py 2
```

---

### 3. 启动桌面悬浮监控 HUD

```bash
python3 tools/antigravity-quota-relay/quota_relay_hud.py
```

- **置顶吸顶**：悬浮窗置顶显示，支持鼠标按住任意位置拖拽到屏幕任何角落。
- **单击切换视图**：单击卡片任意空白区域，可在【双号矩阵概览】与【单号 5 维详细仪表盘】之间无缝切换。
- **一键秒切账号**：在悬浮窗底部直接点击 `[ 1号 ]` 或 `[ 2号 ✓ ]`，瞬间完成热切换。
- **手动刷新**：右上角 `⟳` 按钮支持随时手动立即拉取最新配额（平时后台静默 20 秒自刷新）。

---

### 4. 命令行一键切号（终端场景）

如果在纯终端开发下工作，可直接通过脚本秒切：

```bash
./tools/antigravity-quota-relay/agy-switch.sh 1   # 一键切到 1 号
./tools/antigravity-quota-relay/agy-switch.sh 2   # 一键切到 2 号
```

## 🔒 安全与隐私承诺

- **纯本地存储**：本工具的所有凭据安全存放于本地 macOS 钥匙串与 `~/.gemini/account_vault/`，绝不上报云端。
- **零泄露防护**：仓库全局配置了严格的 `.gitignore`，所有 `*.token`、密钥及本地配额缓存均物理排除在版本控制之外，任何时候 `git push` 都绝不会泄露任何个人凭据。
